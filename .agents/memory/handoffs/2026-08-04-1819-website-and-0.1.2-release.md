## Незавершённое

- Обязательные update smoke tests release runbook не подтверждены пользователем после promotion stable appcast в beta feed:
  - previous beta build 8 → stable build 9 через beta channel;
  - previous stable 0.1.1 → stable build 9 через stable channel.
- Поэтому release нельзя считать полностью закрытым по обновлённому `.agents/rules/releasing.md`, несмотря на успешную публикацию и public artifact verification.

3. После подтверждения дописать outcome в project memory и закрыть release evidence отдельным commit.

- Published tag `v0.1.2` и его assets immutable; не изменять и не загружать assets вручную.
