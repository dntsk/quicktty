OPT-IN / BETA

One stream for the newest build.

Beta is an opt-in channel and a superset of stable: it offers the newest public QuickTTY build, whether that build is a stable release or a beta prerelease. Stable remains separate and never receives prereleases.

quicktty-update-channel = beta

When a stable build is newer than the current beta, beta-channel users receive that stable build and remain subscribed for a later beta with a higher build number.

The beta feed is versioned in the repository and points to immutable application release artifacts. Changing channels does not alter terminal sessions.
