Quake mode

Bring the same live sessions down from the top.

Use the global shortcut to show QuickTTY on the current display. Switch between normal and Quake mode without restarting a shell or rebuilding your split layout.

Broadcast input

Run the same input across every pane in the tab.

Broadcast routes one keyboard event—or one confirmed paste—to every pane in the active tab. The orange tab indicator makes the active state clear.

Mouse, scroll, resize, and interface commands stay local. Broadcast turns off when you leave the tab or workspace.

Find work. Follow progress.

Terminal state stays visible.

Native search

Find text in the active terminal, move through matches, and see the current result count in a native overlay.

Coding-agent progress

OSC 9;4 progress appears in tabs and workspaces, so you can see when an agent is working or waiting.
