GLOBAL ACCESSF12 DEFAULT

Normal ↔ Quake

Drop into the same terminal. Not another terminal.

Quake mode slides the existing workspace from the top of the current display. Toggle back to a normal macOS window without restarting a shell, rebuilding a split, or losing your place.

02 / MULTIPLY

One input.
Every pane in the tab.

Broadcast sends the original keyboard event or confirmed paste to every pane in the active tab. Each terminal interprets the event in its own keyboard mode.

Mouse, scroll, resize, and interface commands stay local. Broadcast turns off when you leave the tab or workspace.
